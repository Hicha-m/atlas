# Contribuer à Atlas Live

1. Ouvrir une issue qui précise le besoin, la source et la fréquence des données.
2. Créer une branche `feat/...`, `fix/...` ou `docs/...` depuis `main`.
3. Ajouter des tests adaptés et exécuter `node --test tests/*.test.cjs`.
4. Ouvrir une pull request vers `main` avec résumé, preuve de tests et captures si l'interface change.
5. Ne jamais committer de secret, token ni donnée personnelle.

## Définition de terminé (module)

Source et licence documentées ; état de fraîcheur affiché ; gestion des erreurs, latence et limites API ; interface responsive ; filtres et visualisations utiles ; export JSON/CSV quand pertinent ; tests et documentation à jour.

# Sécurité

## Signaler une vulnérabilité

Ne publiez pas de faille exploitable ni de secret dans une issue publique. Contactez le mainteneur du dépôt par un canal privé (GitHub Security Advisories si activé).

## Principes

- Aucun secret ni clé d'API ne doit être committé.
- Les contenus externes affichés dans le navigateur doivent être traités comme non fiables.
- Les fournisseurs de données ont leurs propres quotas, conditions d'accès et risques de disponibilité.
- Les mises à jour de dépendances et des GitHub Actions doivent être revues.
- Les tests automatisés ne constituent pas un audit de sécurité complet.
